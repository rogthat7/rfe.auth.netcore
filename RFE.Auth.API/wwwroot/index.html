Built for Production & Agentic AI

Enterprise-grade security standards with frictionless developer experience.

🔒

OAuth 2.1 & PKCE

Strict enforcement of Proof Key for Code Exchange (PKCE) for Single Page Applications (SPAs) and public clients. Zero client secret leaks.

⚡

Model Context Protocol (MCP)

Native Smithery registry integration. Exposes OpenAPI spec endpoints directly as tools to Claude Desktop, Cursor, and Agentic AI runners.

🔑

OpenIddict Core

Built on OpenIddict 7.5 for flexible token management, authorization code flows, refresh tokens, and federated Google/GitHub logins.

🔕

First-Party Auto-Consent

Instant seamless single sign-on (SSO) for internal applications, skipping consent popups while maintaining explicit consent for 3rd-party apps.

📊

Scalar & OpenAPI Specs

Beautiful, responsive API reference powered by Scalar at /scalar/v1 and standard Swagger endpoints at /swagger/v1/swagger.json.

🐘

PostgreSQL & Entity Framework

High-performance database persistence with PostgreSQL schema isolation, indexed user application permissions, and role management.
